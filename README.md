# DDX Coach

Персональный мобильный дневник тренировок по вашему плану **«Тренировка + Питание»** и прогрессу **декабря 2023**.

## Возможности

- План **Пн–Пт** с упражнениями, подходами и целевыми повторами
- Ввод **веса / повторов / подходов** с историей на устройстве (`localStorage`)
- Анатомические визуализации целевых мышц
- Экран **прогресса** (сид из декабрьского дневника + новые записи)
- Подсказки тренера: RPE, прогрессия, питание

## Локально

Откройте `index.html` через любой статический сервер из этой папки:

```bash
npx --yes serve .
```

## GitHub Pages

Сайт публикуется из корня репозитория (ветка `main`).
